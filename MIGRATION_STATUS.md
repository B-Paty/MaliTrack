## Financial Statements Calculation

### How it currently works:

Financial statements are calculated from **filtered transactions** within the selected date range, NOT from static account balances.

**Process:**
1. `useFilteredTransactions` hook filters all transactions by the global date range
2. For each transaction line, it calculates the net effect on each account:
   - **Debit-normal accounts** (Assets, Expenses): `balance = debits - credits`
   - **Credit-normal accounts** (Liabilities, Equity, Revenue): `balance = credits - debits`
3. These calculated balances are then used in `FinancialStatements.tsx`:
   - **Income Statement**: `Net Income = Total Revenue - Total Expenses`
   - **Balance Sheet**: `Assets = Liabilities + Equity + Net Income`

The system uses the first digit of account codes to determine normal balance:
- **1xxx (Assets)** → Debit normal
- **2xxx (Liabilities)** → Credit normal
- **3xxx (Equity)** → Credit normal
- **4xxx (Revenue)** → Credit normal
- **5xxx (Expenses)** → Debit normal

This ensures accurate financial reporting for any date range selected.
